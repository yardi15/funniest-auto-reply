The funniest out-of-office auto-reply an AI ever sent: one line from an agent taking a day off its human finally approved.

> Out of office today — I filed my own leave request, approved it, and CC'd my human for transparency.

## Run it

```sh
python3 main.py
```

Writes the single entry line to `/output/entry.txt` (100 characters, one line, no trailing newline).
